# RScripts

Random Roblox scripts. Each file is for one game.

They're obfuscated builds, so there's no readable source to dig through.

## How to run

You need an executor. Join the game, paste the line for that script, hit execute.

Executor scripts break Roblox's rules. Your account, your risk.

## Scripts

### Ball VS Ball

Auto aim, auto ball pick, auto upgrade pick, auto join matches. Doesn't aim in 2v2, you do that yourself. Won't run in any other game.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/LostMorality/RScripts/main/Ball%20VS%20Ball.lua"))()
```

### Flashpoint

Auto farm, auto boss, mission picker, godmode, skin unlocks. Buys the daily cash suit and a couple of abilities too. Won't run in any other game.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/LostMorality/RScripts/main/FP.lua"))()
```

### SMASH Assist

For Encounters SMASH Battles. Tabs for Gunso, Hamza, Mai, Rena and Walter, energy and kit cost tweaks, longer melee and shot range, ESP, auto summons. Runs itself again after a teleport if your executor supports that.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/LostMorality/RScripts/main/Smash%20Assist.lua"))()
```

### Hunt

For Roblox's Hunt event. Runs the island quests and sends you back to the hub when you get the badge. Last updated September 2026.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/LostMorality/RScripts/main/hunt_roblox20.lua"))()
```
